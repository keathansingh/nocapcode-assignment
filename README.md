# PPSTU Brand Identity

A responsive website presenting the brand identity of PPSTU, from its visual concept to how the identity can be used across different platforms.

The project was built as part of the NoCapCode Full Stack Developer Internship assignment, with a focus on matching the provided design and making the website work across desktop, tablet, and mobile screens.

## Live Demo

https://nocapcode-assignment.vercel.app/

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Features

- Responsive layout for desktop, tablet, and mobile
- Brand identity case study with multiple sections
- Interactive elements and smooth scrolling
- Brand colours and typography presentation
- Chatbot for basic questions about the identity
- Contact form with input validation

## Getting Started

Make sure Node.js and npm are installed on your system.

Clone the repository:

```bash
git clone https://github.com/keathansingh/nocapcode-assignment.git
```

Move into the project folder:

```bash
cd nocapcode-assignment
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Build

To create the production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
